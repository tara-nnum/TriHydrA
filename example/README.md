# TriHydrA fictional example

Open `trihydra_example.ipynb` in Jupyter and run its cells from top to bottom.
The notebook uses four fictional 10-year stations, runs every TriHydrA layer and
comparison, saves interactive HTML diagnostics, and writes NetCDF results.

Inputs are under `data/`. `example_ground_truth.csv` documents the deliberately
inserted teaching anomalies and is not read by TriHydrA. Generated files appear
under `results/`, which is ignored by Git.
